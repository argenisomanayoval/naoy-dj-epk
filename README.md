# ?? NAOY — Digital EPK

Digital Electronic Press Kit (EPK) desarrollado para el proyecto artístico **NAOY**, con una interfaz web moderna, responsive y orientada a la presentación profesional de un DJ.

El proyecto reúne información artística, géneros musicales, lanzamientos, galería multimedia, experiencia y enlaces de contacto/social media dentro de una experiencia digital única.

---

## ? Características

- ?? Hero section con identidad visual del proyecto.
- ?? Sección About para presentación artística.
- ?? Sección de géneros musicales.
- ?? Sección de releases y música.
- ??? Galería para contenido visual.
- ?? Sección de experiencia y colaboraciones.
- ?? Enlaces a redes sociales y plataformas.
- ?? Diseño responsive para diferentes tamaños de pantalla.
- ? Menú de navegación adaptable a dispositivos móviles.
- ? Interacciones y comportamiento dinámico mediante JavaScript.

---

## ??? Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Flexbox
- CSS Grid

---

## ?? Diseño

La identidad visual del proyecto utiliza una combinación de tonos **azules y rosas con un acabado degradado/faded**, buscando transmitir una estética relacionada con la música electrónica y la identidad artística de NAOY.

## ?? Instalación y ejecución

Este proyecto no requiere un servidor backend ni dependencias externas para ejecutarse localmente.

### 1. Clonar el repositorio

\\\ash
git clone https://github.com/argenisomanayoval/naoy-dj-epk.git
\\\

### 2. Entrar al proyecto

\\\ash
cd naoy-dj-epk
\\\

### 3. Ejecutar

Abrir el archivo:

\\\	ext
index.html
\\\

También puede ejecutarse utilizando una extensión como **Live Server** en Visual Studio Code.

## ?? Objetivo del proyecto

El objetivo de NAOY EPK es aplicar conocimientos de desarrollo web para construir una experiencia digital orientada a un caso de uso real.

El proyecto integra estructura semántica, diseño responsive, organización de contenido multimedia e interacciones mediante JavaScript.
